# Compare, меню приложения и диагностика запуска — 2.0.8

15 октября 2026. Дополнительные исправления после приёмки функций F06 / 2.0.7. Зависание запуска остаётся открытым: это диагностическая сборка, без заявления об устранённой причине.

## Исправления

- Перенос карточки Compare больше не включает завесу импорта файлов. Внутренний перенос имеет отдельный MIME; только `Files` включает подсветку. Drop, dragend, уход из области, потеря фокуса и закрытие Compare очищают её. Перестановка и внешний GLB drop сохраняются.
- Общая кнопка скелета управляет Doctor, Compare Grid и Lineup. Cyan-линии и лаймовые суставы построены по фактически видимому animated root, включая независимые Lineup clones. Веса, authored rig и GLB не меняются. Helpers освобождаются при перестроении/удалении.
- Меню ☰ содержит «Настройки» и «Выйти». Настройки меняют существующие язык и helper state; они доступны и поверх Compare. Modal dialog удерживает фокус, Escape возвращает его к меню. Меню поддерживает клавиатуру. Выход вызывает normal window close; прежний guard несохранённых Rig/Heal изменений сохраняется. Cancel оставляет правки, подтверждение разрешает закрытие, ошибки отображаются. В браузерном regression harness Exit отключён.

## Зависание при запуске: подтверждено и неизвестно

Windows Application Hang ID 1002 подтверждает два события `asset-doctor.exe 2.0.7.0`: **01:34:58 и 01:59:10 Europe/Riga** 15 октября. Путь — `E:/MyCreations/Asset Doctor/asset-doctor.exe`; HangType — `Top level window is idle`. Это подтверждение дефекта, без диагноза по одному скриншоту. Вложенные WER Reports недоступны текущей учётной записи; ACL не менялись.

SHA256 установленного EXE совпал с EXE, извлечённым из принятого NSIS 2.0.7: `A4BCA9DA3BE7AF670EB55FD494C2D660E309E909F26E8304BD6791534058C452`. Различие с portable EXE не означает ошибочную версию: bundler патчит тип упаковки. Установщик для проверки не запускался.

Новая диагностика записывает stage-only журнал от `process_start`, Tauri setup/page load и frontend до Doctor construction и первого вызова render. Native timestamps — время получения маркера, без гарантии точного измерения продолжительности frontend constructor. Содержимое моделей, названия файлов и URL в журнал не включены. Максимум 48 событий на запуск; сбой записи не блокирует приложение.

Обычный журнал находится в `%LOCALAPPDATA%/com.constantinejj.assetdoctor/logs/startup-<pid>-<time>.log`. Если через 30 секунд первый render не отмечен, watchdog пишет `startup_timeout`; обычное приложение сам не закрывает. При повторении чёрного/белого экрана нужен журнал именно этого запуска, чтобы определить последний достигнутый этап. Наличие двух renderer contexts при старте измерено, но причинной связи с зависанием не установлено; lifecycle без доказательства причины не переписывался.

Это промежуточный EXE до добавления меню и финальной permission `allow-close`; hash отличается от итоговой сборки. 10/10 не сертифицируют отсутствие редкой ошибки и не заменяют независимую визуальную проверку DWM/первого кадра. Никакие чужие процессы не завершались, установленный EXE не заменялся.

Probe включается только явной переменной `ASSET_DOCTOR_STARTUP_PROBE=visible|hidden`; hidden не проверяет видимое окно. Только probe имеет ограниченное 30-секундное завершение собственного процесса при сбое. Скрипт и все 10 журналов приложены к комплекту.
