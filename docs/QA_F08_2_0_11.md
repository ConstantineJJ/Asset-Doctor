# Asset Doctor 2.0.11 — F08 и пользовательские инструменты

15 октября 2026. База — принятая владельцем 2.0.10, F07 закрыт. Ветка `codex/review-tauri-readiness`. F08 реализован для приёмки; F09 не выполнялся. EXE и installer автоматически не запускаются.

## Что изменилось

1. Explicit MetricsSink вместо prototype instrumentation, публичный memory snapshot Heal, unique backing buffers Mesh/Line/Points/Morph/Interleaved. Retained bytes отделены от transient export измерений. App использует AssetSession и ExportCoordinator для владения root/source/load serial и export publication/busy/revision.
2. Все 11 PNG владельца встроены без изменения; SHA256 совпадает с архивом. Новые Grass/Road/Sand заменяют старые варианты в тех же IDs. Общий каталог Doctor/Compare содержит 19 поверхностей; активные текстуры разделяются и освобождаются через leases. Старый Factory Floor сохранён под прежним именем.
3. ☰ → Настройки → Горячие клавиши: 12 действий, назначение/отключение/reset, проверка конфликтов, сохранение локально, physical keyboard codes для русской раскладки. Клавиши не вмешиваются в ввод и модальные окна; команды Doctor не действуют на скрытую модель при Compare.
4. Жук справа сверху / F8: локальный системный журнал, просмотр/пауза/подробность/фильтр/сохранение JSONL/очистка. Ограниченные UI и disk buffers, ротация 3 × 2 MiB, операции с IDs и итогами, ошибки JS/Worker/import/repair/export/rig. Последняя оборванная disk-строка не уничтожает предыдущие записи при выгрузке. Native stage-only startup traces включаются в экспорт. Подробности лимитов — в [описании реализации](F08_ORCHESTRATION_LOGS_SHORTCUTS.md).
5. Свиток у Focus — отдельная карточка. Нижняя «Логировать всё» / F9 — все текущие ERROR/WARNING/UNKNOWN и MANUAL независимо от страницы/фильтра. JSON содержит model/version/revision/profile/stages, исходное evidence/action/location и локализацию. Partial scan, выборочные индексы и пропуски помечаются явно. Save guard после native диалога исключает устаревшую модель/scan. Текстовые отчёты не снимают защиту несохранённых исправлений GLB.

Native Rust проверяет rotation, invalid input, canonical JSONL и startup stages.

## Ручная приёмка

- Смените пол в Doctor и Compare; проверьте новые 11 изображений и прежние поверхности.
- Назначьте своё сочетание в настройках, проверьте конфликт и сохранение после перезапуска.
- Откройте журнал справа сверху, выполните import/analysis/операцию и сохраните JSONL. Проверьте паузу и очистку.
- Сохраните одну карточку свитком, затем включите фильтр Passed/другую страницу и сохраните всё нижней кнопкой. Общий отчёт должен содержать все неисправности текущего сканирования.
- Повторите привычные Preview/Apply/Undo/Verify/Save и Compare с восемью моделями.

Headless Edge доказывает frontend/runtime поведение на этой машине; Rust harness и Windows build не заменяют ручную проверку установленного WebView2-окна и native Save диалога. F08 закроется после решения владельца. Редкая историческая причина startup hang не объявляется установленной. Частные GLB не входят в поставку и не изменяются.
