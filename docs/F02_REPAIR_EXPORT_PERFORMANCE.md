## Изменение

P1: многосекундные блокировки Repair/Export устранены на согласованном контроле.
Preview и независимые измерения реальной геометрии перед/после Apply выполняются
в worker. Само изменение модели и Undo остаются в существующем движке.
Буферы копируются перед передачей; массивы viewport не отсоединяются.
Полные проверки байтов, layout, групп, morph и stale-состояния сохранены.
Сравнение байтов ускорено точным сравнением слов с проверкой оставшихся байтов.

Экспортный worker получает копии исходника и текущей геометрии. Существующий
экспортный сервис загружает авторский исходник, применяет проверенные изменения,
сериализует GLB и независимо открывает результат. Авторские материалы, изображения,
узлы и клипы берутся из исходника; runtime Material не сериализуется в транспорт.
Повторные одинаковые topology-расчёты кэшируются только для неизменяемых копий
конкретного worker-запроса. Избыточная третья загрузка исходника/изображений убрана.
Диагностические проходы разделены уступками event loop с проверкой актуальности asset.

Ошибка worker до Apply отменяет операцию. Ошибка независимой проверки после Apply
оставляет PARTIAL и Undo; VERIFIED/Export недоступны. Смена модели отменяет работу.
Экспорт заблокирован до завершения всей Safe Queue. F08 не начат.

кэш закреплённых ярлыков/taskbar остаётся для ручной оценки. Installer unsigned.
