# Animation Rig Extension — source-preserving GLB core

TypeScript passes; 190/190 unit tests pass. The core patches canonical source nodes, skins and animation channels and appends replacement streams. Original binary ranges and untouched JSON fields remain exact. Changed samplers detach shared inputs/outputs. Skin joint order/root/name/extras, sparse/interleaved original representations and original material/texture definitions remain in the source document. Known legacy runtime metadata is removed; image data URIs become one embedded image stream.

Verification independently reimports the candidate, checks canonical objects, geometry/morph data, rest transforms, joint ordering, IBMs and clip samples, then compares every vertex in rest and six phases per clip. Function-free worker clip packets restore LINEAR/STEP/CUBICSPLINE, including quaternion normalization, and explicitly enable matrix updates. Serialized replacement bytes and active accessor/view metadata are checked before GLTFLoader can normalize weights. Corrupted original bytes, IBMs, replacement weights and deleted active metadata reject verification.

Additional Codex CLI implementation review found three P1 and one P2 issues: loader-normalized replacement weights could hide serialized corruption; extended imported tip metadata could be overwritten; active gestures did not advance commit revision; rejected drags left an offset handle. The core now validates replacement bytes/metadata, ignores incompatible imported guide schemas while preserving them verbatim, and refuses export/history changes during an active gesture. Native-save/gizmo integration completes the remaining enforcement in the UI increment.

Animation rebasing preserves relative local joint motion using the rigid change of rest. It does not promise identical animated vertex trajectories after moving a pivot; Pose Preview shows the resulting deformation. Rest skin shape and original vertex/weight arrays remain preserved for rig-only edits. Leaf tips are versioned nondeforming author guides; arbitrary original extras and incompatible namespaces are preserved or editing is explicitly rejected.

Limits: self-contained single-scene GLB; renderer-supported four skin influences; supported canonical transform/morph channels. Combined Draco geometry repair, vertex remapping and strip/fan repair require exporting the repair first and reimporting before rig edits. Index-only triangle repair, normal repair and supported skin-weight repairs use authorized replacement streams; all other attributes retain their raw source data. Unknown modified accessor/view extension semantics reject export. KTX2 verification requires renderer support and remains conservative.

Sources: [glTF 2.0 skins and Appendix C](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html), [Three.js SkinnedMesh](https://threejs.org/docs/pages/SkinnedMesh.html), [TransformControls](https://threejs.org/docs/pages/TransformControls.html). Exact installed Three.js 0.186.1 loader/mixer/skinning code was inspected. No application version change.
